      🌐 Browser version — this page
      
      
      Runs 100% in your browser. Fetches the page (directly, or through a public CORS proxy when a site blocks direct fetching), strips scripts and styles, and shows clean text, the heading outline and every link.
      
    
      
    
      
      
      💻 Local version — Selenium + AI
      
      
      The Python app (aiweb.py) drives a real Edge browser with Selenium, so it handles JavaScript-heavy pages, then a local Ollama model extracts exactly what you describe. Nothing leaves your machine.
      
    
      
    
      
      
      ⚖️ Scrape politely
      
      
      Only scrape pages you're allowed to, respect each site's terms and robots.txt, and don't hammer servers. This tool is for learning and personal projects.
